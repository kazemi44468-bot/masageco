# گروه تخصصی ماساژ

وب‌سایت مستقل گروه تخصصی ماساژ؛ طراحی و توسعه بر پایه استاندارد مادر `sakhtar` و با هویت بصری اختصاصی پروژه.

## استانداردهای فعال
- هدر دولایه با لایه دوم خدمات و رفتار مینیمال هنگام اسکرول
- RTL و mobile-first با منوی موبایل اختصاصی
- فونت‌های فارسی مستقل در `assets/fonts/` و بدون CDN
- Breadcrumb در صفحات داخلی
- Back to Top در صفحات طولانی
- 404 مستقل و هم‌هویت با پروژه
- Admin Access مرکزی از طریق `data/site.json`

## وضعیت
نسخه پایه Front-end در حال توسعه است. معماری برای اتصال آینده به CMS، API و پایگاه داده آماده نگه داشته می‌شود.
